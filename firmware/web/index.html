Relay

In relay mode the stack light fetches its state from a relay server on the internet (relay/ in the repository) instead of waiting for hooks on the local network. Create a key with the role lamp in the relay's admin interface. The local controls keep working, but the relay's next change overwrites them.

The channel sweep turns channels 1 to 5 on one at a time and reports on the serial console which colour is expected. This is useful for checking after replacing a lamp or when a loose contact is suspected. If a different lamp lights up than the one announced, swap the entries in include/config.h.
